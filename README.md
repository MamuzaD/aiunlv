## Features

- Responsive landing page for club information, workshops, schedules, projects, and officers
- Project and event gallery with reusable cards, dialogs, and image viewing
- Mobile navigation and scroll-based animations
- Content-driven structure for straightforward club updates

## Development

```bash
pnpm install
pnpm dev
```

No environment variables are required.
